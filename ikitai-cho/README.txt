いきたい帖（オフライン版）— 使い方

■ このフォルダの中身
  index.html             アプリ本体
  sw.js                  オフラインで動かすための仕組み（Service Worker）
  manifest.webmanifest   ホーム画面に追加したときの名前・アイコン
  icon-*.png             アイコン
  seed/                  最初から入っている2件の写真

■ iPhoneでオフラインで使うまで（最初の1回だけネットが必要）
  1. このフォルダの中身を、HTTPSで公開できる場所に置く
     例）GitHub Pages：新しいリポジトリにこのフォルダの中身をそのままアップロード
         → Settings → Pages → Branch を main / (root) にして Save
         → 表示された https://〜.github.io/〜/ のURLを開く
     （Netlify や Cloudflare Pages など、ほかの無料ホスティングでもOK）
  2. iPhoneのSafariでそのURLを開く
  3. 共有ボタン →「ホーム画面に追加」
  4. 以後はホーム画面のアイコンから起動。機内モードでも動きます。

■ データの保存先
  ・場所の情報と写真は、iPhone本体の中（アプリ専用の保存領域）に保存されます。
    サーバーには送られません。
  ・機種変更やアイコン削除でデータは消えます。トップ画面下部の
    「書き出す」でバックアップ（.json）を作り、「ファイル」アプリなどに保存してください。
    「読み込む」で戻せます。
  ・Googleマップを開くボタンだけは、ネット接続が必要です。

■ アプリを更新したとき
  ファイルを差し替えたら、sw.js の CACHE の名前（ikitai-cho-v1）を v2 などに変えてください。
  ネットにつながった状態で一度開くと、最新版に切り替わります。
